# Моноскопическая визуальная одометрия для комплексной оценки по системе 4 камер на основе ORB-SLAM3

## Общее описание

Проект **моноскопической визуальной одометрии** с использованием **четырёх камер**, расположенных по кругу (front, back, left, right) позволяет комплексно оценивать поворот и перемещение на коротких расстояниях с масштабированием в метрические координаты, а также оценивать поворот и перемещение с помощью отдельных камер. Использование только камер для комплексной оценки движения повышает точность результата без испотьзования дополнительных датчиков: IMU часто вносит значительный шум при длительном движении с низкой скоростью, а колёсные энкодеры не учитывают проскальзывания.

## Требования к работе

- Текстурированное окружение
- Проезд 10-20 см прямолинейно для инициализации

## Предварительная подготовка

Основной код состоит из 3 файлов, находящихся в папке **multi_stereo**:

- **stereo_config_USB.py/stereo_config_ABCD.py**
- **track_stereo.py**
- **multi_track_stereo.py**

**stereo_config_USB.py/stereo_config_ABCD.py** - файл конфигурации системы со всеми настраевыми параметрами. Приписка "_USB" относится к роботу, приписка "_ABCD" - к стенду.
Основные настройки файла конфигурации - это `CAMERA_CONFIGS`. В нём для каждой камеры отдельно устанавливаются минимальные пороги инициализации (основные - `score_threshold`: минимальный порог ошибки, `min_parallax_deg`: минимальный параллакс и `min_inliers_init`: минимум хороших точек).
А также устанавливаются калибровочные параметры `mapp_coeff`, `img_size`, `dist_cnt` и `stretch_matrix`. При этом `mapp_coeff` содержит коэффициенты a0, a2, a3 и a4 (коэффициент a1 пропускается).
Помимо этого у каждой камеры необходимо указать путь к видео для обработки, который вносится в переменную `video_path` и расположение каждой камеры `placement` (`front`, `back`, `left` или `right`).

Также важным является `CROSS_CALIB`, где настраиваются параметры стереокалибровки соседних камер (матрица поворота **R** и вектор переноса **t**).
Параметры индивидуальной и совместной калибровки камер находятся в папках:
- **Cam_ABCD_calib_param** - индивидуальная калибровка камер стенда
- **Cam_USB_calib_param** - индивидуальная калибровка камер робота
- **Cam_USB_stereo_calib_param** - совместная калибровка камер робота (в двух форматах - matlab и текстовый документ)

В файле можно настроить сохраняемые логи и визуализацию в `LOGGING_CONFIG` и `RECORDING_CONFIG` соответственно.

Возможно, необходимо настроить ключевые кадры в `KEYFRAME_CONFIG`, основная переменная: `min_matches` - минимум точек для создания ключевого кадра. Или может понадобиться настройка `PNP_CONFIG`, основная настройка - `ba_iterations`: количество итераций PnP + алгоритм Левенберга-Марквардта для уточнения позиции кадра.

**track_stereo.py** - файл алгоритма для обработки данных с каждой камеры отдельно. В файле прописывается только подключение конфигурационного файла

**multi_track_stereo.py** - файл алгоритма для совместной обработки данных с камер. В файле прописывается только подключение конфигурационного файла

## Запуск программы

Для запуска алгоритма необходим запуск файла **multi_track_stereo.py** с полной настройкой путей к видео в конфигурационном файле:
```./multi_track_stereo.py```

## Логирование

Программа позволяет сохранять:
- **01_settings.csv** - настройки, пороги, калибровки. Включение через `settings`
- **02_keyframe_points.csv** - 3D-точки ключевых кадров. Включение через `keyframe_points`
- **03_motion_points.csv** - 3D-точки, участвующие в оценке движения. Включение через `motion_points`
- **04_frame_motion.csv** - перемещения/повороты/статистика по кадрам. Включение через `frame_motion`
- **05_scale_summary.csv** - сводка совпадений и масштаба слева/справа. Включение через `scale_summary`
- **06_scale_points.csv** - поточечные масштабы с соседними камерами. Включение через `scale_points`
- **07_local_unit_motion_counts.csv** - счётчики приведённых локальных условных перемещений. Включение через `local_unit_motion_counts`
- **08_local_unit_z_motion.csv** - глобальные метрические перемещения и повороты. Включение через `global_metric_motion`
- **final_window.avi** - финальное видео работы. Включение через `save_final_window`
- **keyframe_reprojection.avi** - видео репроекций точек на ключевой кадр для отладки. Включение через `save_keyframe_reprojection`

## Дополнительные файлы

- **graph_scale.py** - построение графиков масштаба по логам. Необходимо в файле указать путь к логам (**05_scale_summary.csv**) в переменной `csv_path`. Запуск: ```./graph_scale.py```
- **play_out_video.py** - воспроизведение видео из логов для отладки. Необходимо в файле указать путь к логам в переменной `VIDEO_PATH`. `A` - следующий кадр, `D` - предыдущий кадр, `Q` - остановка. Запуск: ```./graph_scale.py```
